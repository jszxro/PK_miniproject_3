# 📚 Bukjeokx2 - 전자 도서 대출 시스템

**Bukjeokx2**는 누구나 쉽고 빠르게 책을 빌릴 수 있는 **PyQt5 기반의 전자 도서관 시뮬레이션 프로그램**입니다.  
복잡한 도서관 시스템의 대안으로, 직관적인 UI와 핵심 기능에 집중한 도서 대출 경험을 제공합니다.

## 🧩 핵심 기능

### 사용자 기능
- 회원가입 / 로그인 (역할 기반 분기: 관리자/사용자)
- 도서 목록 조회 및 상세 보기
- 도서 대출 및 반납 처리
- 대출 상태 확인 및 알림 표시

### 관리자 기능
- 도서 등록, 수정, 삭제
- 회원 목록 관리 (조회 / 수정 / 삭제)
- 도서 상태 변경 및 전체 흐름 모니터링

## 📂 주요 테이블 설계

| 테이블명 | 설명 |
|----------|------|
| `BOOKINFO` | 도서 정보 (제목, 저자, 상태 등) |
| `CUSTOMERINFO` | 사용자 정보 (이름, 이메일, 권한 등) |
| `BORROWINFO` | 대출 내역 정보 (대출일, 반납일 등) |
| `DIVTBL` | 도서 분류 정보 |

- 도서의 대출 상태(`LOAN_YN`)를 기반으로 대출 가능 여부 판단  
- 이메일 로그인 시 사용자 ID 조회 후 기능 분기  
- 반납 시 DB 상태 복원 + `BORROWINFO` 테이블 갱신
